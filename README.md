# BMI Calculator

A simple and modern Body Mass Index (BMI) Calculator built using **HTML**, **CSS**, and **JavaScript**.

## 🚀 Features

* Clean and modern UI
* Takes height (cm) and weight (kg) as input
* Calculates BMI instantly
* Displays BMI category: Underweight, Normal, or Overweight

## 📂 Project Structure

```
BMI-Calculator
│
├── indexTwo.html

└── scriptTwo.js
```

## 🧮 How BMI is Calculated

```
BMI = weight (kg) / (height (m) * height (m))
```

Example:

```
Height = 170cm → 1.70m
Weight = 60kg
BMI = 60 / (1.70 * 1.70) = 20.76
```

## 📝 Steps to Use

1. Enter height in centimeters.
2. Enter weight in kilograms.
3. Click on **Calculate**.
4. Your BMI and weight category will be displayed.
