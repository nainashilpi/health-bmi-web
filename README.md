# BMI Calculator 💙

A simple and modern **BMI (Body Mass Index) Calculator** built using **HTML, CSS, and JavaScript**.  
This project helps users calculate their BMI and understand their weight category based on standard BMI ranges.

---

## 🚀 Features
- Clean and modern UI (Glassmorphism Design)
- Takes Height (cm) and Weight (kg) as input
- Calculates BMI accurately
- Displays BMI result + weight category (Underweight / Normal / Overweight)

---

| Technology | Purpose |
|-----------|----------|
| HTML      | Structure |
| CSS       | Styling & UI Design |
| JavaScript | BMI Calculation Logic |
